# 通用图案板生成

## 使用范围与首要闸门

用于跨主题二维商业印花。不要默认任何节日、固定元素、色板、装饰或具体构成；这些变量必须为当前主题重新确定。

先读仓库 `AGENTS.md`、当前用户要求和已有主题档案。使用当前 checkout，不自行创建工作树。

在调用任何图像生成或编辑工具前，先判断这是否为当前对话中新主题的第一轮：

- 是：只输出中文简短建档，包含主题、核心元素及主辅建议、配色建议、构成建议，可附一句画风推荐；明确“本轮不生成图片”并结束本轮。首轮中的“直接生成”不解除闸门。
- 否：继续检查当前输出是否有明确生成授权。系统讨论、参考上传、画风选择或旧对话授权本身不构成当前生成授权。

## 执行步骤

1. **建档与简报**：新主题第一轮执行首要闸门。后续记录受众、用途、禁用项、数量、输出类型、尺寸和循环目标；分开标记已确认、建议和待定，最多追问一个真正阻塞的问题。
2. **参考分析**：逐图记录可访问性、来源和职责，分开观察与推断。用户参考或 Moodboard 只提炼明确气质、元素、配色角色与装饰倾向；外部案例先审美再匹配。没有图时声明文字推导。不得复制独特纹样、品牌、文字、水印或摄影布景。
3. **视觉 DNA 与 P 选型**：建立当前主题的元素语法、色彩面积、造型成熟度和系列不变量。实际查看官方 P PDF，选一个主 P，最多一个备选；P 控制画法，不提供主题元素。用户指定 P 未经授权不得更换。
4. **图案板规划**：逐款写设计卡：主/辅 C、第一层骨架、完整重复单元、方向、节距、尺度、密度、留白、背景职责、边缘策略、配色分工和输出规格。C 编号不能替代结构描述；多格不能只换背景或大小。
5. **生成双闸门**：确认新主题已完成首轮建档；当前输出已有明确授权；主题、类型、数量、必选/禁用项、P、构成和修改范围可执行。任一硬条件缺失则不调用图像工具。
6. **仅授权生成**：一次只生成获授权的一张。默认图案板是 2×2 四格，明确六格为 3×2；各格真 1:1、白缝约格宽 1–2%，仅含满版二维图案，无标题、色卡、说明、Logo、产品或场景。单元素、单款满印或定位图案按明确要求输出。
7. **分层检查**：依次记录 D 任务与格式、A 平面化/P 纯度、B 构成、C 商业审美与配色、E 元素细节、L 循环证据，使用通过/需修/未验证。提示词含 `seamless` 或整板看似连续只能算概念；L3 需要独立图块、四边四角和 3×3 拼接证据。
8. **定向修改**：先拆分已认可并锁定、需要改变、仍未验证三类。仅改用户点名且授权的维度；已认可构成不能因修画风或配色被重做。区分设计问题与生成执行问题，不能用反复重生图替代判断。
9. **归档**：保存用户原话、锁定项、产物、检查证据和经验状态（候选/已分析/实测通过）。不把“改善”“勉强可用”升级成正式通过或官方标准，不擅自发布或对外发送。

## 停止条件

用户要求阶段性审阅时，完成该阶段后停止。图像生成未授权时，可交付规划及待确认项，但不得调用生成工具。资料导入、规则维护或系统讨论不构成新主题生成授权。
