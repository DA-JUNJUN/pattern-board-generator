## 失败案例的可复用错误族

现有资料包含 F01–F35 和 F37–F39；其中 F01–F13 只有摘要，F36 未提供。可读取的失败信息可归为：

- 越过新主题建档或当前生成授权；一次生成多于授权数量；
- 把图案板做成海报、产品、场景或静物插画；
- 建议冒充确认，跨主题继承元素、配色、装饰或题材；
- P 未核对、混合主导技法、复杂度上升后写实化；
- C 标签与真实骨架不符，随机散点、背景贴纸化或规则格纹失真；
- 构成、画风、配色和细节混为一项，修改时破坏已认可内容；
- 将概念图、提示词或“勉强可用”写成完全通过或严格无缝；
- 小尺度结构错误、辅助元素无职责、参考重复或审美门槛不足。

失败图不得进入优秀案例库，也不能成为下一主题的画风锚点。现有摘要、详细记录与回归用例见 [`10_失败案例与回归测试_v7.md`](source-materials/10_失败案例与回归测试_v7.md)；不要把缺失的 F01–F13 详情、F36 或 T29 写成已读取。

## 待验证经验与升级规则

- 经验状态统一为候选、已分析、实测通过；适用范围必须随状态记录。
- “改善”“略有提升”“勉强可用”只能记录为基本可用或候选，不是完整通过。
- 个案中有效的亮粉、暖柔和底色、蝴蝶、格纹或其他元素不能跨主题默认继承。
- 现代 P1/P2 的色块优先、局部撞色与有限纹理是条件性校准，不能覆盖 P3/P4 官方定义。
- 构成被用户认可后，画风或配色修改应锁定构成；这条可作为通用反馈方法。
- 单元素通过不能推断单款满印或 4/6 格通过；L1 概念不能推断 L3 循环通过。
- 来源文件提出的“根因待验证”必须保留为未验证，不通过文档改写宣称已排除。
