# C1–C10 构成语法

C 规定结构，不决定 P 画风。每款先写可执行骨架，再记录主 C 和必要的辅 C；编号不能替代设计描述。

| C | 固定名称 | 核心结构与验收 |
| --- | --- | --- |
| C1 | 多尺度错落散点 | 独立元素按方向、尺度、间距形成节奏，避免随机均匀撒点 |
| C2 | 连接延展与生长 | 枝条、藤蔓、串灯、珠链或飘带形成真实连接，挂点与遮挡合理 |
| C3 | 完整单元规则重复 | 完整单元先成立，再作阵列、错行、半落位或色彩节奏 |
| C4 | 方向性条带与边框 | 明确横纵方向、端部和连续带状关系，不只是背景条纹 |
| C5 | 中心定位与独立组合 | 主体围绕中心或偏心组织留白，是定位构成，不伪装四方循环 |
| C6 | 主题组合叙事 | 元素在动作、用途或语义上形成完整组合，再进入重复节奏；不是照片场景 |
| C7 | 结构底纹与主题元素复合 | 格纹、条纹、棋盘或菱格形成秩序，小元素与其节距、层级发生关系 |
| C8 | 框格容纳与分区 | 框形作为容器，内部内容、留白与重复对位统一 |
| C9 | 多花型拼布拼接 | 多个自主完整的小花型分占区块并按拼布节奏连接 |
| C10 | 基础几何与极简阵列 | 独立几何或简化单位形成规则格纹、棋盘、菱格、条纹或点阵，可无主题元素 |

## 易混边界

- C7 是结构底纹与主题元素复合；纯几何或极简规则单元优先 C10。
- C8 是框格容器；C9 的每个区块本身是自主完整花型。
- C3 重复完整单元；C8 由容器决定内部装饰。
- C2 是自然连接与生长；C4 是规则方向性带状装饰。
- C1 排列独立物件；C6 先形成有意义的完整组合，组合本身仍可按 C1 排列。
- 徽章按实际结构归入 C3、C1 或 C8，不新增编号。

## 设计卡最小字段

主/辅 C、第一层骨架、完整重复单元、方向、节距、密度与尺度、留白、边缘关系、背景与主体层级。抽离题材和配色后仍看不出不同组织方式时，应修改骨架而不是添加装饰。

多格可以重复同一 C，但必须在主体、节奏、尺度、结构或用途上有实质差异；不为凑齐 C 编号引入不适合主题的构成。
