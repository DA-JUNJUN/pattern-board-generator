# 官方画风定义与视觉核对

## 官方共同客户风格底层

成熟、精致、面向当代欧美大众零售餐厨、家居、礼品和包装的二维商业印花。形态有设计，比例自然或合理装饰夸张，色彩有面积角色，图案骨架有节奏。允许局部明暗、高光、结构线和手绘肌理；精致度不能主要依靠真实体积、镜面反光、空间投影、摄影透视或 3D 材质。动物不自动等于幼态儿童风。

这是一套官方默认审美底层。用户当前项目、品牌或市场要求可覆盖具体客户定位；题材、元素、色板和装饰仍须每次重新确定。

## P1–P4 固定定义

| P | 官方定义 | 2026-10-29 PDF 页面视觉核对 |
| --- | --- | --- |
| P1 现代局部颗粒平涂手绘 | 干净平涂、哑光色块、有机轮廓，颗粒与同色叠色只局部使用 | 第 1 页可见花瓣、叶片和丝带以平涂为主，局部有细颗粒和干刷感；没有全图均匀纸纹 |
| P2 结构细节扁平手绘 | 干净实色、明确结构块与少量二维叠色；无颗粒、水彩、纸纹和 3D 材质 | 第 2 页边缘最清楚，花瓣、叶片和丝带以内部分区色块表达结构，几乎无颗粒与水洗晕染 |
| P3 固有色清透水彩 | 透明水洗、有限叠染、边缘积色与纸白，同时保留明确固有色和装饰轮廓 | 第 3 页可见透明色层、深浅水痕、纸白与柔和积色；整体仍是平面花束而非空间写实 |
| P4 经典欧式装饰手绘 | 不透明水粉或广告色块面、克制彩色轮廓、方向明确的笔刷；传统感来自比例、秩序和层次 | 第 4 页色块更不透明，花瓣和叶片有方向性笔触及彩色轮廓，层次丰富但没有厚重油画塑形 |

## 使用规则

- 选择 P 前实际查看对应 PDF 页；只读文字不能写成已完成视觉匹配。
- P 只决定画法，不决定主题、元素、配色或 C 构成。
- 主体、动物、植物和小装饰必须共用主导画法；复杂度上升不授权写实化或混合 P。
- P1 颗粒仅局部；P2 不混水洗纸纹；P3 水彩仍保持二维装饰属性；P4 不等于任意复古水彩或厚重油画。
- 官方 PDF 中的花束与蝴蝶结只用于同元素画风对照，不得机械带入新主题。
- 记录“已查看官方页”与“已实际输入图像生成工具”两个事实；前者不等于后者。

资料文字提到四张对应 PNG，但本次压缩包未包含这些 PNG；当前可核对的权威视觉载体是四页 PDF。
