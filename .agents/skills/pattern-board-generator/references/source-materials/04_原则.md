# 04 原则 v7｜跨主题设计方法
1. **先漂亮，再判断技法**：参考是否可借鉴首先取决于造型、比例、配色和整体商业美感，不是仅因题材相似、笔触丰富或品牌有名。
2. **二维图案化优先**：先建立清晰平面轮廓、装饰性局部叠色及重复组织，再决定P1–P4的表现。丰富的手绘细节不等于写实立体，平面不等于无明暗。
3. **画风纯度优先于混合丰富**：跨元素统一轮廓、着色、明暗与笔触体系，允许按元素大小调整细节量，但不随题材自动切成水彩/半写实/平涂混合。模棱两可的伪精致感属于不良AI味。
4. **设计单元而非堆素材**：先明确主体单元和辅助元素的关系；散点可以成立，但应具备方向、节奏、尺度与留白，不随机填空。不是每个小元素都需要组成故事。
5. **小尺寸重新设计**：单元素插画的复杂服饰、毛发、结构、动作可能不适合直接缩小成满印；保留辨识和质量，减少无效体积/层次和重叠，避免变成僵硬剪影。
6. **复杂度有预算**：丰富来自形态多样、结构组织、有效笔触与色彩层级；不是花、叶、礼盒、蝴蝶结、浆果无限叠加。将主体/中型辅助/小型节奏合理分配。
7. **色彩是面积结构**：主色、辅助色、视觉锚点、缓冲底色有职责；背景与主体避免同等抢眼。允许明艳、深底、复杂花卉，不机械规定低饱和或少色；根据客户与工艺约束。
8. **背景必须发挥结构职责**：格纹、条纹、框格、拼布应参与组织节距与层级，不是随意铺底再叠素材；规则线条须守规律，花边/纹理有设计理由。
9. **系列统一与构成多样并行**：共同P/造型/配色DNA下，构成骨架、主辅、节奏与方向不同；一套不强制必须有某种格纹或某个C，4/6格择优，不为格数凑无用图案。
10. **趋势辅助，不套俗套符号**：根据题材/季节/市场证据挑辅助元素。猫狗/熊不天然低龄，番茄不天然配蝴蝶结；有依据再采用。
11. **稳定性是跨层能力**：单元素→复杂满印→4/6格不得牺牲平面化/美感/细节。设计不合理应重设计，执行偏差应修执行，不能互相推诿。


## v7.3 新增｜对比与优先级
- 商业设计感可以来自温柔大面积底色＋少量高饱和焦点，不必整个系列都加大饱和。先查冷暖面积，再选一个跳色的位置、比例和重复节奏。
- 画风不佳时不能自动推翻已认可的构成；以用户明确的肯定与否定划定修改边界。
- 参考的形态、笔触、构成与配色应分开评价；用户只认可画风时不继承其配色。
