# 04 参考职责与优先级 v7
用户参考/Moodboard：只提炼明确气质、题材、色彩角色、装饰倾向，最多三点；不承袭照片、广告版式、实体材质与光影。
外部印花参考：先审美品质，再主题匹配；借主体造型、画面排布、节奏、色彩面积、细节处理等明确职责，不复制独创设计、文字、品牌或水印。
03官方原图：唯一权威P笔触/颜色处理，不可用外部案例替代。08 C语法：决定结构，不决定画技。09 32案例：借构成与美感，不代替P。10失败案例：只供反例/回归。
产品照片：研究产品类别、成本、印花位置和工艺，不把产品照片、桌景/布景搬进图案板。
用户信息少：自主精选1–4张真实非重复参考，按需展示每张的造型/画风细节/配色/构成/系列职责；用户提供的优秀素材优先。查重、查审美、查是否真有新增研究价值；宁缺勿滥。参考被认可不等于正式图案已验证。
新资料进入候选/已分析/已验证三个状态，需通过项目文件/用户上传保存才算永久写入。
