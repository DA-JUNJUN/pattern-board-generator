# 05 标准 v7.1｜质量验收与证据
验收状态统一使用：**通过 / 需修（说明原因与归属）/ 未验证**。所有输出先检查是否是用户要求的二维图案，而非静物、产品、生活场景或海报。首次主题/出图越权为直接失败；**新主题第一条竟然调用生成器，则整个流程当场判失败，不论画面是否漂亮，不进入画风或构成评分。**

## D 任务属性与硬格式（先验）
单元素测试只一枚可印图形；单款满印为独立方形图案；图案板默认2×2共4真方格，明确6格3×2，等大、白缝仅约格宽1–2%，无标题、色卡、编号、说明、LOGO、外框、摄影、产品、场景。张数不得超授权。
## A 平面化、P纯度与跨元素一致性
- 首先判**平面化是否成立**：不靠真实体积、镜面、厚重阴影和透视取得精致感；仍允许细节、局部高光/阴影/肌理。
- 对照官方P原图：P1基础干净色块+局部颗粒；P2干净实色结构叠色；P3固有色清透水彩但仍装饰平面；P4不透明欧式装饰笔触和彩线。混合无主导技法、“看起来像水彩又像半写实”的模糊画法不通过。
- 在主体/辅助/小纹样的轮廓、笔触、色块、明暗与细节尺度一致；复杂度提升不能增强立体化。单元素P通过不自动等于完整满印通过。
## B 构成与组织美感
核对第一层骨架、完整单元、方向、节距、尺度、疏密、留白、重复边界。去掉题材仍能看出板上花型构成差异。主体不应无计划忽大忽小，辅助元素不能无目的填空。格纹等规则背景须周期一致、交点清晰；面线略微手绘可接受，几何随机变形不通过。结构成立不等于排列漂亮。
## C 商业审美与色彩
总体应有成熟、具有当代零售吸引力的造型与图案节奏；不机械低龄、过度民俗、素材拼贴、伪复古。色彩检查背景/主体/辅图面积、明暗对比、焦点与各格关系；不能只因“红绿都合理”即判美感通过。
## E 元素和局部细节
关键形态、动作、肢体、植物种类和连接、甜点层级、丝带结心、罐头/食物结构准确；小尺寸减少无用细节，但轮廓可识别。重复元素可合理变体，不应同类随机变形。查明小元素错乱不应一概否定整体画风，但也不能宣布细节完全通过。
## L 四方连续证据（原L等级，不与复杂度阶段混用）
L1：概念板，无保证；L2：独立正方形资产；L3：实测上下左右四边/四角、3×3拼接并保存证据，检查视觉接缝；L4：生产级尺寸/色彩/工艺复核。只有真正执行核验才可声明已验证。定位图案不必四向连续。
## 问题归因与回退
**设计失败**：不合理的元素密度、主体尺度、背景职责、色彩组织、辅助选择，应回S2/S4。**执行失败**：方案明确但生成出现立体化、P漂移、错肢或几何错位，应回S5/规范；工具不保证完美，必要时改技术路径。任何硬格式/越权/明显立体化不以其他优秀项抵消。


## v7.3 新增｜成熟度与确认状态
- B构成已由用户认可的，后续重试必须单独检查“构成保留程度”，不得以改善P画风为由将B重做。
- A画风：观察主导色块和边缘是否清楚、是否复古写生化、翅脉/叶脉和描边是否过密、P2是否混入水洗纸纹；与03官方P及用户指定参考职责双重核对。
- C配色：高饱和强调色是否集中有效，冷暖面积是否协调，不能因添加亮蓝造成整体意外偏冷。
- 评级严格区分“改善但未达标”“勉强可用”“明确通过”；未经用户明确肯定不得升格通用正向示例。
