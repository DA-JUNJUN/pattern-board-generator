# 构图规则

## 通用原则

- 用主元素、辅助元素和填充元素建立视觉层级；并非每个主题都必须具备三类。
- 用尺度、间距、方向与重复建立节奏，避免无意义堆叠和机械均匀散布。
- 负空间应服务于用途和可读性，不把高密度或低密度固定为优选。
- 避免无意切断、边缘挤压、近切相碰及局部重心失衡。
- 系列通过共同的 DNA 统一，通过板位角色与构成变化形成分工。
- 默认产物是二维平面印花设计；产品样机、透视场景或立体渲染需另行明确需求。
- P 负责画风，C 负责构成；不能从 C 名称推断笔触，也不能用 C 编号代替实际骨架。

## 逐主题确定的参数

| 参数 | 记录方式 |
| --- | --- |
| 板位角色 | 主视觉、配套、底纹等，按用途选择 |
| 元素尺度 | 主辅比例及目标使用尺寸下的可读性 |
| 密度与留白 | 目标疏密、区域分布及理由 |
| 方向 | 单向、双向、多向或无明显方向 |
| 构成方式 | 散点、网格、条带、簇群等，按主题选择 |
| 色彩分工 | 背景、主体、辅助及点缀的面积关系 |
| 循环方式 | 不要求循环，或指定平接、半落等方式 |

C1–C10 的固定名称、边界和易混判定见 [构成语法](../.agents/skills/pattern-board-generator/references/composition-grammar.md)。不要求一套板凑齐十种 C，也不因多格使用同一 C 自动判错；关键是结构和用途有实质差异。

## 内容、形态与构成匹配

先确定该款的内容职责和主体形态，再选能支持它的 C 骨架：

- 独立且轮廓清楚的单体可进入散点或规则阵列；规则阵列中的完整单元必须容易辨识和稳定重复。
- 枝、藤、串、链或动作关系只有在连接真实合理时才使用连接结构；孤立图标加一条线不算成立。
- 切面、局部或内部结构适合在其确实提供新轮廓、色块或识别信息时使用，不能成为跨主题必选项。
- 多主体组合会增加信息量，背景、留白和辅助层级应相应收敛；复杂内容不再叠加无职责装饰。
- 格纹、条纹和棋盘与主题元素必须在节距、交点、容器或遮挡关系上发生作用；纯几何协调纹可以主动不放主题主体。
- 线稿、极简单位和小尺度符号适合安静协调纹，但仍须与系列的轮廓、线宽和色彩 DNA 一致。

不要为了覆盖更多 C 类型而选择不符合元素外形、主题语义或目标市场气质的结构。C 的差异不能补偿内容同质，也不能自动证明商业审美成立。

## 整板节奏与互补检查

从整套板而非单格检查：主体内容是否有变化；完整、组合和简化形态是否互补；大中小尺度、密集与疏朗、方向性与无方向性是否形成节奏；视觉重点和安静协调纹是否各司其职；背景明暗和色彩面积是否平衡。若两款的主体轮廓、视角、尺度和重复节奏同时接近，应合并、替换或明确不同用途。

“现代”“成熟”“零售感”等定位须转成可检查决策，例如减少对称民俗装饰、控制轮廓复杂度、集中强调色、建立清楚重复单元或为高信息图案保留安静背景。没有市场数据或用户参考时，只能记录为设计推断，不能宣称已验证为流行趋势。

## 花型家族与色彩变体

商业系列不要求每格都使用不同 C。一个成熟的主花可以发展为不同背景、有限色路或尺度的同族变体，条纹、格纹、单色密纹和小图标也可组成协调家族。变体必须有明确职责，例如适配不同产品、明暗搭配或降低视觉重量；不能把整板全部做成同一花型换底色。整板仍需同时具备足够的主辅层级、尺度节奏和安静/丰富关系。

参考图中的元素总览页可用于检查元素库，系列板可用于研究主花、协调纹、色路和密度分组；总览页的标题、品牌、排版和产品展示不能进入纯图案板。

## 图案板规划最小字段

板位 ID、角色、重点内容与主动省略、主体形态与表现方式、辅助元素职责、主/辅 C、第一层骨架、完整单元、方向、节距、密度与尺度、留白、边缘关系、背景职责、配色分工、与其他板的互补、选择理由、共享 DNA、输出规格和验收关注点。

若要求严格无缝循环，生成后须对左右、上下及四角接点进行检查，并查看 3×3 平铺；只有单幅图、整板概念或提示词写了“无缝”不能视为验证通过。
