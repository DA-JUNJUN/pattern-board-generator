# 分阶段制作与 A/B 反馈

## 默认制作流程

新主题仍先文字建档。后续采用：参考校准 → 主题元素库设计 → 元素验收 → 花型家族规划 → 独立正方形花型 → 固定尺寸拼板 → 循环检查 → 用户反馈。

1. 元素库先说明主体、辅助、小协调单位的轮廓、结构、线条、色彩和表面处理。文字清单不代表已经拥有可复用图像资产。
2. 有授权的元素测试先检查造型、画法与完成度；不达标则记录问题，不能用复杂排布遮盖。用户认可后保存独立素材及版本，作为各款共同参考；模型参考输入不保证精确复用。
3. 花型家族明确每款重点内容、形态、省略、骨架、尺度、密度、背景和色路。具体题材与板位每次重新判断。
4. 商业制作优先分别制作独立方形花型，再以确定尺寸拼成纯图案板。拼板保证格数、尺寸和白缝，不自动证明元素一致、商业质量或无缝。
5. 需要循环交付时，逐款检查四边、四角和 3×3 平铺，保存证据；未做则保持 L1/L2。

快速概念模式仍可一次整板生成，用于方向比较；须明确独立资产、精确复用和循环尚未验证。用户明确只授权一张整板时采用此模式，不擅自增加元素图或六次独立生成。

## 生成预算与 A/B

用户已同意后续测试可采用 A/B 两版。新主题首轮仍不生成；后续进入明确生成测试时，可以制作 A/B，记录两版各自的目的及实际调用数。若用户本轮限定一张，优先遵守一张限制。

元素测试图、候选图、独立花型和最终生成板均属于生成资产，应在执行前列明数量及阶段。两张最终板不等于允许无限中间生成；完整制作路径需要覆盖其实际中间数量的授权。程序拼板和检查不额外生成新设计，但仍保存操作证据。

A/B 保持主题、必选元素、受众、用途与输出规格一致，优先只改变一项有价值的方向，例如画法、色路或花型家族策略；不要同时任意改变所有变量。不得预设 B 更优或生成第三版。

## 给用户的反馈表

| 维度 | 选择 A / B / 都可 / 都不满意 | 补充或填空 |
| --- | --- | --- |
| 元素造型 | 待填写 | 希望保留___；需要改变___ |
| 画风与表面 | 待填写 | 线条/笔触/边缘/明暗___ |
| 构成与节奏 | 待填写 | 喜欢第___格；原因___ |
| 配色 | 待填写 | 保留___；减少___；增加___ |
| 系列搭配 | 待填写 | 更像一套的是___；不协调处___ |
| 商业完成度 | 待填写 | 明确通过 / 基本可用 / 需修；用途___ |

反馈后分别记录：用户明确认可并锁定、希望改变、仍未验证。局部喜欢不代表全板通过。A/B 比较属于当前主题证据，跨主题方法仍需复验；落选方案保留为历史证据。
