# 质量验收标准

## 状态与证据

执行级验收统一记录为通过、需修或未验证；需修须标明设计问题、生成执行问题或工具限制。管理性信息可以另记待确认或不适用并说明理由。通过须提供产物和检查证据；尚未生成图像时，不得将视觉质量判定为通过。

| 维度 | 验收要求 |
| --- | --- |
| 需求匹配 | 主题、受众、用途与禁用项得到满足 |
| 商业审美 | 以目标品类、用户确认的审美基准及实际使用尺度评审，避免用主观赞美替代依据 |
| 视觉 DNA | 形态、线条、纹理、配色角色与已确认规则一致 |
| 构成逻辑 | 层级清楚、节奏有意图、负空间合理、无意外切碰 |
| 系列协调 | 画风统一，各板角色和尺度疏密有有效差异 |
| 平面性 | 保持约定的二维语言，无非预期场景、样机或体积效果 |
| 图像完整性 | 无明显畸变、脏点、意外文字、水印及异常元素 |
| 循环质量 | 要求循环时，边缘、四角及平铺重复无断裂和明显接缝 |
| 技术规格 | 实查尺寸、格式、透明度和色彩模式，不依赖生成说明推断 |
| 生产适配 | 若用于量产，另核实最小细节、色数、工艺、色彩管理及实物打样；没有证据时标未验证 |

## D/A/B/C/E/L 检查顺序

1. **D 任务与硬格式**：输出类型、格数、几何、禁止内容和授权张数。
2. **A 平面化与 P 纯度**：二维属性、官方 P 主导技法及跨元素一致性。
3. **B 构成与组织**：骨架、完整单元、方向、节距、尺度、疏密、留白、背景和边缘。
4. **C 商业审美与色彩**：成熟度、零售吸引力、面积角色、冷暖、明暗和焦点。
5. **E 元素细节**：关键形态、动作、连接和小尺寸识别；局部错误单独记录。
6. **L 循环证据**：L1 概念、L2 独立正方形资产、L3 四边四角及 3×3 实测、L4 生产规格复核。

## 判定与修改

- 新主题首轮调用生成工具或授权缺失：流程直接失败，不进入画风评分。
- 关键需求、DNA、构成或适用的循环检查失败：本版不得标为验收通过。
- 未验证项必须披露；文档检查通过不等于图像、循环或生产验收通过。
- 每个修改项记录：板位及位置、观察证据、严重程度、修改目标、必须保持的规则、授权范围与复查结果。
- 商业审美最终需用户结合用途确认，不能仅由自动检查宣称达标。
- “改善”“略有提升”“勉强可用”不得升级成完全通过或正向案例。
