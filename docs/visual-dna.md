# 视觉 DNA 提炼

视觉 DNA 是当前主题系列可重复执行的视觉约束，不是抽象形容词列表。官方 P 提供画法基准，但题材、元素、配色和装饰仍由每个主题独立确定。

| 维度 | 主题档案需记录的内容 |
| --- | --- |
| 主题语义 | 核心叙事、情绪、受众与避免的联想 |
| 元素语法 | 主元素、辅助元素、填充元素及简化方式 |
| 元素库质量 | 核心单体的轮廓、结构、视角、线条、内部细节和小尺度识别 |
| 内容分配 | 各款重点表现、允许组合、局部辅助与主动省略的内容 |
| 形态谱系 | 合理的完整/局部、单体/组合、视角、连接、姿态、实形/线稿变化 |
| 形态 | 几何或有机、轮廓倾向、比例与细节层级 |
| 线条 | 有无线描、线宽关系、边缘与笔触特征 |
| 色彩 | 色值或色样、主辅点缀角色、面积比例、背景与对比 |
| 平面表达 | 色块、有限层次、纹理与阴影规则；避免意外体积渲染 |
| 完成度剖面 | 边缘精度、手绘感来源、纹理尺度、明暗方式、细节密度与允许误差 |
| 构成 | 尺度、方向、负空间、疏密、节奏和循环方式 |
| 系列变化 | 固定项、可变项及各板差异化范围 |

官方 P1–P4 固定定义、PDF 视觉核对和使用边界见 [官方画风定义](../.agents/skills/pattern-board-generator/references/official-styles.md)。P 与 C 独立：同一个 P 可用于不同构成，同一个 C 也可由不同 P 表现。

## P 画法与商业完成度分离

官方 P 用于确定平涂、水彩、颗粒或装饰笔刷等主导画法，不单独证明元素漂亮、细节成熟或整套系列具有市场吸引力。用户提供的优秀系列参考可以定义完成度和商业气质，例如轮廓是否精细、植物结构是否可信、线条是否有个性、表面是哑光还是光滑、色彩变体如何组织；这些观察不得覆盖官方 P 的技法边界，也不得复制参考中的完整图案。

多格前先建立元素库清单。至少挑核心主体、辅助植物/物件和一个小协调单位，逐一说明轮廓特征、内部结构、线条、色块/纹理、允许的明暗和目标尺度。若单体仍是通用素材感、球体高光或无区别的基础几何，不能只靠复杂排布掩盖，应先回到元素库校准。

## 系列内容与形态分配

多格系列先建立整板分配表，再进入单款构成。分配表至少回答：每款重点表现什么、采用哪一组形态、哪些元素只作辅助、哪些相关元素因气质或用途不适合而排除，以及该款如何补足其他款。主元素不要求在所有花型中以同一形态出现，也不要求每款容纳完整元素清单。

形态变化从主题真实结构中选择，例如完整与局部、单体与组合、合理视角、独立与自然连接、彩色实形与轮廓线稿。只使用对当前主题有意义且在目标尺度可识别的变化；不得为了“丰富”强造不合理切面、连接、姿态或局部符号。

内容数量不是质量指标。单一主体可以形成有力主花，少量几何或线稿可以承担协调纹；多主体组合只有在语义、轮廓和层级均成立时才使用。具体元素、形态和板位均为主题变量，不能从单个成功案例固化为跨主题模板。

## 色系层级与整板视觉重量

使用多色色板前先区分主导色系、第二核心色系、辅助色和中性缓冲底；色板包含某色不等于该色适合成为大面积底色。分别检查每格与整板的背景面积、饱和度、明度和对比：辅助色即使色块不多，也可能因明亮底色抢占风格。需要时减少面积或降低饱和度/明度对比，但调整具体色值须遵循当前用户要求。

此方法来自情人节天鹅 A/B 用户反馈，已分析、待修订后复验；粉红主导、蓝紫第二、黄辅助是主题条件，不作跨主题默认。

## 记录要求

- 主题关键词只能支持配色建议，不能锁定惯用节日色盘。用户色板到达后撤销冲突的旧建议，重新分配全系列色彩角色；多色板不等于每款全色或等量使用。
- 分开识别色样的颜色、载体造型和表面质感；只借配色时，不继承厚涂反光或立体材质。屏幕 Pantone 标签不等于已核对官方印刷色。
- “包含某元素”不等于该元素必须占多数或出现在每款；依用户要求规划各内容家族的主次轮换，并检查与相邻季节/节日的语义区分。

- 每条规则附来源：参考图编号、用户要求或设计推断。推断不能冒充参考图事实。
- 使用可检查的描述，例如“轮廓使用同一线宽层级”，而非仅写“高级、好看”。
- 色彩比例和尺度等参数可先提出建议，未确认的数值保留为建议值。
- 参考冲突时记录冲突、取舍理由和待确认项，不将不同画风机械拼接。
- 无参考图时写明“基于文字简报提出的 DNA，待用户确认”，不得虚构图像分析。
- 官方 P 图中的花束与蝴蝶结只是画风对照元素，不得继承为新主题元素。
- 记录官方页是否已查看，以及是否实际传入图像生成工具；两个事实不能混写。
- 单元素确认的 DNA 应传递到复杂满印和多格，但后续层级仍需单独验收。
- 整板缩略图检查内容重复：若去掉背景后多格仍由近似轮廓、视角和组合主导，应先重做内容—形态分配，而不是仅换 C、底色或密度。
