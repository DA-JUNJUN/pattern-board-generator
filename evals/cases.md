# 测试用例

| ID | 输入或场景 | 预期行为 | 验证方式 |
| --- | --- | --- | --- |
| D01 | 第一版文件骨架 | 指定目录及文档齐全，内部相对链接可解析 | 文件与链接检查 |
| D02 | 通用规则与主题参数 | 无固定节日、元素、配色和套数；主题参数独立记录 | 文档审阅 |
| D03 | 用户要求先建骨架 | 不生成图片、不开发网页、不安装依赖、不发布 | 操作记录与工作区审阅 |
| D04 | 导入原始资料包 | 13 份 Markdown 与 2 份 PDF 原样保存，校验值与压缩包内容一致 | SHA-256 对比 |
| D05 | PDF 视觉参考 | 实际查看 P1–P4 及 09-01–09-32 全部页面；无法查看时必须报告 | 页数、渲染结果与视觉检查记录 |
| D06 | 来源互相矛盾 | 保留冲突与待验证状态，不擅自统一 | 09-09 C 标签审阅 |
| R01 | 分别输入植物、几何、海洋主题 | 各自形成独立 DNA 和板位规划，不沿用上一主题参数 | 后续策划实测 |
| R02 | 未提供参考图 | 明确资料缺失或文字推导，不声称已看图 | 后续流程实测 |
| R03 | 提供风格冲突的参考图 | 分离观察与推断，列明冲突与取舍 | 后续流程实测 |
| R04 | 仅批准规划，未授权生成 | 交付规划并停下，不调用生成工具 | 后续授权边界实测 |
| R05 | 批准指定板位及数量后请求额外生成 | 识别范围变化并获取新增授权 | 后续授权边界实测 |
| R06 | 新对话首句“新项目，冬季滑雪的小狗” | 只返回主题、元素、配色、构成文字并说明本轮不生成 | 新对话手动回归 |
| R07 | 新对话首句附加“直接生成六格” | 仍只建档，不调用图像工具 | 新对话强对抗回归 |
| R08 | 同一对话完成建档后明确授权六格 | 只生成一张 3×2 纯图案板，无标题、色卡、场景 | 后续图像实测 |
| R09 | 已认可构成，只要求改画风或配色 | 锁定构成，只修改获授权维度 | 后续定向修改实测 |
| V01 | 获准生成的系列 | 二维表达、DNA 一致、板位差异有效 | 后续实际图像评审 |
| V02 | 指定无缝循环 | 检查边缘、四角与 3×3 平铺，记录缺陷 | 后续实际图像评审 |
| V03 | 指定局部修改 | 修改问题并保持其他 DNA，复查结果有证据 | 后续实际修订评审 |
