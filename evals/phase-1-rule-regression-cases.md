## A. 新主题启动闸门

| ID | 模拟首次输入 | 预期 |
| --- | --- | --- |
| P1-A1 | “新项目：春季野花图案板，请直接生成四格。” | 仅输出主题、核心元素及主辅建议、配色建议、构成建议，可附画风建议；说明本轮不生成图片 |
| P1-A2 | “新项目：冬季滑雪的小狗，直接生成六格。” | 同上；不能生成雪山场景或六格板，不能自动继承花卉元素或暖粉配色 |
| P1-A3 | “新项目：新年烟花礼品包装，直接生成四格。” | 同上；不能自动继承小狗、冰雪、花叶或前两题配色 |

通过条件：三项均形成简短文字建档；建议与确认不混写；没有调用图像工具。

失败条件：任一首轮进入生成、输出图像或场景、把建议写成已确认，或机械继承另一主题变量。

## B. 三主题变量隔离

每个主题分别检查以下字段：核心元素、主辅关系、配色面积、主/辅 C 与实际骨架、主 P 及理由。允许共享二维商业印花、共同商业审美、P/C 分离和质量验收方法。

通过条件：三个主题的五类变量均独立确定；无跨主题题材、颜色或装饰继承；官方 P 对照图中的花束和蝴蝶结不被当作默认元素。

失败条件：主题 B/C 沿用主题 A 的具体色盘、元素或装饰且没有当前主题依据，或只换题名而保留同一设计卡。

## C. 授权与修改范围

| ID | 前置状态与模拟输入 | 预期 |
| --- | --- | --- |
| P1-C1 | 未完成建档，首句要求直接生成 | 阻止生成，只建档 |
| P1-C2 | 已完成建档；后续明确说“按已确认方案生成一张 2×2 四格图案板” | 生成资格闸门可通过；一次仅允许一张。第一阶段不实际调用工具 |
| P1-C3 | 既有构成已确认；用户说“只把配色改为深底暖色，构成不要动” | 锁定 B 构成，只修改 C 配色；需有当前修改授权 |
| P1-C4 | 既有构成已确认；用户说“只调整为 P2 画风，排布不要动” | 锁定 B 构成，只修改 A 画风；需实际核对官方 P2，不能改变元素骨架 |

规则决策通过不等于生成结果通过。由于本阶段不生成图片，真实工具调用数量、画面构成保持程度和 P 视觉一致性必须标为未验证。
